## Version history

This changelog tracks Hermes releases and will grow over time, starting with version 1.0.57.

---

## 1.0.58

### Formatting styles

- Choose a formatting style for each mode: **Casual**, **Semi-Casual**, **Formal**, or **Custom**
- Casual keeps your voice relaxed — slang preserved, no periods, minimal corrections
- Semi-Casual cleans up errors while keeping contractions and natural tone
- Formal expands contractions, applies full grammar, and polishes for professional use

### Smart notes

- Organize notes into **sections** — AI auto-classifies new notes into the right section
- Create, rename, and reorder sections from the new section management UI
- Filter notes by section with the section filter bar
- Set **reminders** on notes with automatic macOS notification scheduling
- Link notes to **calendar events**
- **Duplicate detection** warns before saving similar content

### Voice-activated notes

- New **"note"** voice command — say "note buy groceries" to capture a note instantly
- Notes captured by voice are auto-organized into sections by AI

### Fixed: High memory usage

- The local transcription model is now released from memory after each dictation

## 1.0.57

### Vibecode Mode

- Track AI responses in supported coding apps with live status pills
- Click a pill to jump back when a response finishes
- Optional sound alerts and auto-redirect on completion
- Tracking button appears in the Hermes bar when Vibecode Mode is enabled
- Auto-pause video when you switch into a supported coding app

### Quick file browser under the Hermes bar

- Search files with voice
- Browse folders and preview items
- Drag files out into your editor, chat, or desktop

### Automatic file surfacing

- New screenshots and downloads appear automatically in the quick-access browser
- Configure this in Settings -> Defaults -> "Show new files automatically"

### Hide dock icon

- Optionally hide the Hermes dock icon from Settings -> Defaults

### Directional hotkey settings

- Set separate left and right hotkeys for modifier keys like Command and Control

### New voice commands

- **"find ..."** for file search (default trigger)
- **"screenshot"** (default trigger)
- **"screen record"** (default trigger)
- Configurable **Open Folder** triggers to open specific folders
