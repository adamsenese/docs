## Version history

This changelog tracks Hermes releases and will grow over time, starting with version 1.0.57.

---

## 1.0.57

### Vibecode Mode

- Track AI responses in supported coding apps with live status pills
- Click a pill to jump back when a response finishes
- Optional sound alerts and auto-redirect on completion
- Tracking button appears in the Hermes bar when Vibecode Mode is enabled
- Auto-pause video when you switch into a supported coding app

### Quick file browser under the Hermes bar

- Search files with voice
- Browse folders and preview items
- Drag files out into your editor, chat, or desktop

### Automatic file surfacing

- New screenshots and downloads appear automatically in the quick-access browser
- Configure this in Settings -> Defaults -> "Show new files automatically"

### Hide dock icon

- Optionally hide the Hermes dock icon from Settings -> Defaults

### Directional hotkey settings

- Set separate left and right hotkeys for modifier keys like Command and Control

### New voice commands

- **"find ..."** for file search (default trigger)
- **"screenshot"** (default trigger)
- **"screen record"** (default trigger)
- Configurable **Open Folder** triggers to open specific folders
