## Appearance

| Setting | Default | Options |
|---------|---------|---------|
| **Theme** | Auto | Light, Dark, Auto (follow system) |
| **Font Size** | Medium | Small, Medium, Large |
| **Animations** | On | Enable or disable UI animations |
| **Compact Mode** | Off | Use a denser UI layout |

### Theme

- **Light**: Bright interface, good for daytime
- **Dark**: Dark interface, easier on the eyes at night
- **Auto**: Follows your macOS appearance setting

---

## Hermes bar

The Hermes bar is the floating interface that appears when you dictate.

| Setting | Default | Description |
|---------|---------|-------------|
| **Position** | Bottom Middle | Where the bar appears on screen |
| **Follow Active Screen** | On | Bar appears on the screen you're working on |
| **Hide When Inactive** | Off | Hide the bar when not dictating |

### Position options

| Position | Description |
|----------|-------------|
| Top Left | Upper-left corner |
| Top Middle | Upper-center |
| Top Right | Upper-right corner |
| Bottom Left | Lower-left corner |
| Bottom Middle | Lower-center (default) |
| Bottom Right | Lower-right corner |

### Multi-monitor setup

When **Follow Active Screen** is on, the Hermes bar appears on whichever screen has your active window. This is useful if you work across multiple monitors.

Turn this off if you want the bar to always appear on your primary monitor.

---

## Menu bar

| Setting | Default | Description |
|---------|---------|-------------|
| **Show Menu Bar Icon** | On | Display Hermes icon in the macOS menu bar |

The menu bar icon provides quick access to:
- Start/stop dictation
- Open Hermes
- View recent dictations
- Access settings

---

## AI widget

| Setting | Default | Description |
|---------|---------|-------------|
| **Corner Position** | Bottom Right | Where chat bubbles and AI responses appear |

When using features like Hermes Chat, responses appear in a floating widget. This setting controls which corner of the screen it uses.
