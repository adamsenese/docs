## Appearance

| Setting | Default | Options |
|---------|---------|---------|
| **Theme** | Auto | Light, Dark, Auto (follow system) |
| **Font Size** | Medium | Small, Medium, Large |
| **Animations** | On | Enable or disable UI animations |
| **Compact Mode** | Off | Use a denser UI layout |

### Theme

- **Light**: Bright interface, good for daytime
- **Dark**: Dark interface, easier on the eyes at night
- **Auto**: Follows your macOS appearance setting

---

## Hermes bar

The Hermes bar is the floating interface that appears when you dictate.

### Moving the bar

Drag the Hermes bar to reposition it. You can place it in these locations:

- **Top Middle** or **Bottom Middle**
- **Any of the 4 corners**

The bar remembers its position between sessions.

### Hiding the bar

Drag the bar off the edge of the screen to hide it. Drag it back onto the screen to show it again.

## Menu bar

| Setting | Default | Description |
|---------|---------|-------------|
| **Show Menu Bar Icon** | On | Display Hermes icon in the macOS menu bar |

The menu bar icon provides quick access to:
- Start/stop dictation
- Open Hermes
- View recent dictations
- Access settings
