## Find Files

Use the **Find Files** action to search your Mac and show results below the Hermes bar.

**Default trigger:** `find ...`

**Example**
- Say: "find budget spreadsheet"
- Hermes shows matching files in the quick file browser

---

## Open Folder

Use **Open Folder** to open a specific folder in the quick file browser.

1. Go to **Settings -> Triggers**
2. Create a new trigger
3. Choose **Open Folder** as the action type
4. Select a folder path

**Example**
- Trigger phrase: `projects`
- Result: Opens your Projects folder under the Hermes bar

---

## Screenshot

Use **Screenshot** to capture an area of your screen and surface the file right away.

**Default trigger:** `screenshot`

**How it works**
- Hermes opens the macOS area screenshot selector (Cmd+Shift+4)
- The saved screenshot appears in the quick file browser

---

## Screen Record

Use **Screen Record** to open the macOS screen recording toolbar.

**Default trigger:** `screen record`

**How it works**
- Hermes opens the recording toolbar (Cmd+Shift+5)
- When you finish recording, the file appears in the quick file browser
